# Security policy

## Report a vulnerability

Use [Quivra's private vulnerability report form](https://github.com/pixel-brewery/quivra/security/advisories/new). Keep vulnerability details and proofs of concept out of public issues and pull requests.

Include the output of `quivra --version`, the affected commit if you built from source, your operating system, and the command that reproduces the issue. If the behavior depends on an OpenAPI document or a MiniJinja profile, share a minimal example with secrets, private URLs, and customer data removed. Explain the impact and any known workaround.

Reports may cover the Quivra CLI, its built-in profile templates, the npm launcher, and code generated by the built-in profiles. For other bugs, use the [public issue tracker](https://github.com/pixel-brewery/quivra/issues).
