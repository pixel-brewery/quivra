OpenAPI clients shaped by your templates

Quivra reads your OpenAPI document and generates TypeScript. Your MiniJinja profile controls the client, its dependencies and the files written to your project.

Download Quivra Read the profile guide

Generate a client

Download a native binary for macOS, Windows or Linux, or install @pixel-brewery/quivra from GitHub Packages.

quivra init --preset fetch --out profiles/fetch
quivra generate openapi.yaml --profile profiles/fetch --out src/api
quivra generate openapi.yaml --profile profiles/fetch --out src/api --check
